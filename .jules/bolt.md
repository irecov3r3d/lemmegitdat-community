## 2024-05-28 - Missing DB Indexes and unbounded queries
**Learning:** The initial database schema for the FoodMarket SQLite application was missing critical indexes for frequently queried columns (`region_id`, `ingredient_id`, `status`, `created_at`), which would cause full table scans on every `GET /api/price-reports`, `GET /api/best-price`, and during the expiration routine. Furthermore, the base query returned unbounded results, which could cause memory issues on large data sets. Also `.gitignore` was missing `server/data/` which is a critical learning about the setup of this repository.
**Action:** When working with SQLite in Node, explicitly check `.schema` or queries for missing indexes, and ensure queries that might fetch unbounded data include `LIMIT` clauses. Always check if the local DB files are properly `.gitignore`d before creating commits.
